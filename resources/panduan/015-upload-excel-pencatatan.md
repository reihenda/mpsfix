1. Buka detail customer.
2. Di bagian **Riwayat Pencatatan**, klik **Template Excel** untuk mengunduh format yang benar.
3. Isi template: satu baris untuk satu pembacaan (waktu dan angka meter awal/akhir). Jangan ubah judul kolom.
4. Klik **Upload Excel**, pilih file (.xlsx atau .xls), lalu proses.
5. Cek tabel **Riwayat Pencatatan** untuk memastikan data masuk dengan benar.

> Pastikan harga untuk bulan-bulan di file itu sudah diatur, supaya biaya dan saldonya langsung benar.
